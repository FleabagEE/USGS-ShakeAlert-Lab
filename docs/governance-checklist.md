# Governance Checklist

## Phase 0 review

- [ ] Safety owner and engineering approver named.
- [ ] Passive-only scope acknowledged by all participants.
- [ ] Risk register reviewed and owners assigned.
- [ ] Interlock and source-safety checks pass.
- [ ] No secrets exist in source, fixtures, logs, or evidence.
- [ ] No CUBE/PX-01 repository or system has been modified.
- [ ] Repository retention and evidence-handling rules approved.

## Phase 1 review

- [ ] Dedicated future lab-host requirements reviewed.
- [ ] Supported Ubuntu release confirmed from sanitized inventory.
- [ ] UTC/time synchronization evidence passes thresholds.
- [ ] Baseline packages are justified; protocol packages remain deferred.
- [ ] Network information template contains no guessed endpoints.
- [ ] Firewall proposal reviewed but not applied.
- [ ] Phase 0 and Phase 1 acceptance reports approved.

No Phase 2 work may start without separate written authorization.
